# ♻️ Waste Classification Using Deep Learning

## 📌 About

A Deep Learning-based web application that classifies waste images using **MobileNetV2 Transfer Learning**.

## 🗂️ Classes

* Cardboard
* Glass
* Metal
* Paper
* Other Garbage

## 🛠️ Technologies

* Python
* TensorFlow / Keras
* MobileNetV2
* Flask
* HTML, CSS, JavaScript
* TensorFlow Lite
* Render

## ⚙️ How It Works

```text
Upload Image
     ↓
Preprocessing
     ↓
MobileNetV2
     ↓
Waste Classification
     ↓
Prediction + Confidence
```

## ▶️ Run Locally

```bash
pip install -r requirements.txt
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
